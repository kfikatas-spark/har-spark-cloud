# WISDM HAR με PySpark — Πακέτο υποβολής

**Κωστας Φύκατας** · Πλατφόρμες και Αρχιτεκτονικές Νέφους

## Από πού ξεκινώ;

1. **har-wisdm-report-el.pdf** — κύρια αναφορά, 15 σελίδες: πρόβλημα, μέθοδος, αποτελέσματα και περιορισμοί.
2. **har-wisdm-presentation-el.pdf** — παρουσίαση, 14 διαφάνειες, με γραφήματα και οπτική εξήγηση των δύο μοντέλων.
3. **har-wisdm-technical-companion-el.pdf** — συμπληρωματική τεχνική τεκμηρίωση, 39 σελίδες· δεν αποτελεί την κύρια αναφορά.
4. **har-spark-cloud-redesigned.svg** — συνολική αρχιτεκτονική.
5. **har-function-map.html** — διαδραστικός χάρτης συναρτήσεων. Ανοίγει τοπικά σε browser: επιλέξτε στάδιο, πλαίσιο ή σύνδεση. «Προσαρμογή» επαναφέρει ολόκληρο το διάγραμμα στην οθόνη.

Τα πέντε αρχεία είναι αυτοτελή, όχι συμβολικοί σύνδεσμοι. Δεν απαιτούν ενεργή cloud εφαρμογή ή σύνδεση σε λογαριασμό για να διαβαστούν. Οι εξωτερικοί βιβλιογραφικοί σύνδεσμοι χρειάζονται Internet.

Μόνο τα παραπάνω πέντε αρχεία αποτελούν τα τελικά έγγραφα για τον διδάσκοντα. Ο κώδικας και τα τεκμήρια παραδίδονται χωριστά· τα README και οι οδηγοί κώδικα είναι βοηθητικό υλικό, όχι πρόσθετες αναφορές.

## Κώδικας και τεκμήρια

Το **supporting/** περιέχει κώδικα, ρυθμίσεις, tests, αποθηκευμένα μοντέλα/μετρικές, γραφήματα και οδηγίες αναπαραγωγής. Ξεκινήστε από το **supporting/README.md**.

Τα αποτελέσματα αφορούν τα αποθηκευμένα πειράματα της **27-08-2026**. Η προετοιμασία της υποβολής στις **11-09-2026** δεν εκτέλεσε νέο cloud πείραμα και δεν έλεγξε τρέχουσες χρεώσεις. Δεν περιλαμβάνονται κωδικοί, browser profiles, το προαιρετικό web dashboard ή το μεγάλο αρχείο αρχικών μετρήσεων.

Το **SHA256SUMS** επιτρέπει έλεγχο ακεραιότητας των παραδοτέων.
